# Tech by Math

*The mathematics under the systems people use every day: databases, Spark, Kafka, search, git, Kubernetes. One tutorial per lasting idea, not one per product, because Kafka, Pulsar and Kinesis rest on the same math. Each tutorial is built to be learned with a pencil: a real question, the math worked by hand on a tiny example, why it is true, the same numbers from the real system, where it breaks, and exercises with hidden answers.*

| Course | What it covers |
| --- | --- |
| [The data engineering core](data-engineering-core/index.md) | Joins as set math, B-trees, query planning, transactions, column files, Spark shuffles and skew, mergeable aggregates, Kafka logs and lag |

Later, in this order: **distributed systems** (quorums, clocks, Raft, CAP and FLP, consistent hashing, caches, counting huge sets) and **everyday systems** (search, vector search, git, diff, Kubernetes scheduling, task graphs, compression, percentiles and A/B tests).

The math itself is taught on the sister sites, so these tutorials link to it instead of repeating it: [Math](https://math.akadian.ca/) (probability, statistics, linear algebra, logic), [Computer science](https://cs.akadian.ca/) (algorithms, machine learning), [Networks](https://networks.akadian.ca/) and [Cryptography](https://cryptography.akadian.ca/).
