   first full at t = 97 s; by hand about 10,000 / (300 - 200) = 100 s (a little sooner here,
   because each second the 300 arrive before the 200 leave)
   highest queue 10,200: the limit is checked before a run, so one run can pass it
   throughput once throttled: 200/s; wait of the last 20,000 FlowFiles: about 49.5 s
   Little's law: wait = queue / throughput = 10,000 / 200 = 50 s
