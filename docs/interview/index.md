# Interview prep

*Practice for the coding tests and questions that come before an IT job offer.*

Each guide here is about the test itself: how it works, how to plan the time, and many practice tasks with the
answers folded away. The subject teaching lives in the courses (SQL under [Databases](../databases/index.md)), and
the guides link to the chapters.
