# Tech by Math: the earlier drafts (August 2025)

> **Earlier draft, not yet checked.** These folders are copies of the repos in
> [github.com/tech-by-math](https://github.com/tech-by-math), written in August 2025. Many formulas in them have no
> source, some "proofs" claim more than is true (for example, git's "same hash if and only if same content": SHA-1
> collisions were made in 2017), and the team stories are invented. Do not use them as facts.

They are kept here as raw material for the checked tutorials on the **Tech by Math** shelf of it.akadian.ca
(`docs/tech-by-math/`). This folder is outside `docs/`, so the website does not publish it. Each system is rewritten
there one idea at a time, with the math worked by hand, every example run and tested, and sources.
